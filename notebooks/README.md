# Notebooks

Este directorio contiene análisis exploratorios y visualizaciones. La lógica reutilizable o
necesaria para reproducir un experimento debe trasladarse a `src/anuraset_dl/` y cubrirse con
pruebas.

## Contenido

- [`01_dataset_analysis.ipynb`](01_dataset_analysis.ipynb): auditoría parametrizable de
  metadatos, audios, grabaciones, sitios y distribución multietiqueta. Usa el dataset local actual
  por defecto y puede exportar un resumen JSON de forma opcional.
